# RentMor — strona internetowa i aplikacja Android

Repozytorium obsługuje **RentMor.pl** (publiczną stronę, panel administracyjny i API) oraz natywną aplikację Android **Pro RentMor** (`pl.rentmor.protokol`), używaną do zarządzania wynajmem sprzętu, rezerwacjami, protokołami, wiadomościami klientów i statystykami.

## Stan projektu i historia aktualizacji

**[Otwórz aktualny rejestr postępów RentMor →](docs/RENTMOR-PROJECT-LOG.md)**

W rejestrze są: zrealizowane poprawki strony i aplikacji, wersje, linki do PR, częściowo wdrożone funkcje, znane luki, priorytety i datowana historia pracy. **Przed nową propozycją lub zmianą sprawdź go, aby nie dublować wykonanych prac.**

Wytyczne prowadzenia dziennika przy każdej kolejnej zmianie: [AGENTS.md](AGENTS.md).
